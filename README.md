# SpringBootAndAPIFundamentals


> **Repositório educacional** voltado para compreender o funcionamento interno das camadas de uma aplicação **Spring Boot REST**.

---

## 🇧🇷 Sobre o Projeto
Este repositório tem como objetivo **estudo e registro conceitual** de como as principais camadas do backend **Java + Spring Boot** se conectam e interagem.  
⚠️ **Importante:** este projeto **não é executável**,  contém apenas exemplos de código organizados por camadas.

### 🧠 Camadas estudadas (Resumidas)
- **Entity** → Representa as entidades do domínio.  
- **Enum** → Define tipos enumerados usados nas entidades e na lógica de negócio.  
- **DTO (Data Transfer Object)** → Transporta dados entre camadas.
- **Mapping / Mapper** → Realiza a conversão e transformação de dados entre entidades e DTOs.
- **Repository** → Responsável pela persistência e acesso aos dados.  
- **Service** → Contém as regras de negócio e validações.  
- **Controller** → Expõe endpoints REST e controla requisições HTTP.

### 🧰 Tecnologias Utilizadas
| Tecnologia | Descrição |
|-------------|------------|
| **Java 17** | Linguagem principal |
| **Spring Boot** | Framework base |
| **Maven** | Gerenciador de dependências |
| **MySQL (via XAMPP)** | Banco de dados em ambiente local |
| **JPA / Hibernate** | Mapeamento objeto-relacional |
| **Spring Data JPA** | Repositórios e consultas |
| **Spring Web (REST)** | Exposição de endpoints HTTP |

## 🇺🇸 About the Project
This repository is an **educational record** to understand how the core layers of a **Spring Boot REST backend** interact and work together.  
⚠️ **Note:** this is **not a runnable project** , it contains only structured code examples organized by layer.

### 🧠 Studied Layers
- **Entity** → Domain entity representation.  
- **Enum** → Enumerated types used in entities and business logic.  
- **DTO (Data Transfer Object)** → Transfers data between layers.  
- **Repository** → Handles data persistence and access.  
- **Service** → Contains business rules and validations.  
- **Controller** → Exposes REST endpoints and handles HTTP requests.

### 🧰 Tech Stack
| Technology | Purpose |
|-------------|----------|
| **Java 17** | Core language |
| **Spring Boot** | Main framework |
| **Maven** | Dependency management |
| **MySQL (via XAMPP)** | Local development database |
| **JPA / Hibernate** | ORM layer |
| **Spring Data JPA** | Repository abstraction |
| **Spring Web (REST)** | RESTful API exposure |
